# Compendium Builder Skill

Builds an authoritative, cross-disciplinary knowledge vault for an expert's niche.

## The 4-Layer Taxonomy Guide

When mapping the user's niche, never accept generic topics. Require fundamental thinkers and mental models for each layer:

| Layer | Weight | What It Contains | Good Examples | Bad Examples |
| :--- | :--- | :--- | :--- | :--- |
| **1. Philosophy & First Principles** | 30% | Timeless ethics, epistemology, stoicism, systems theory | Marcus Aurelius, Epictetus, Taleb, Popper | "How to be happy", "Motivation" |
| **2. Psychology & Cognitive Mechanics** | 30% | Mental biases, subpersonalities, shadow work, behavioral economics | Carl Jung, IFS Richard Schwartz, Kahneman | "10 psychological tricks" |
| **3. Biology / Science / Systems** | 20% | Physiological constants, neurotransmitters, somatic rhythms, hard data | Huberman, Sapolsky, Walker (Sleep), Attia | "Eat healthy", "Drink water" |
| **4. Applied Tool / Framework** | 20% | The creator's concrete calculation, architecture, or workflow | Matrix calculation, Code linter, Notion OS | "My secret sauce" |

## Output Generation

Populate `templates/DOMAIN_COMPENDIUM.template.md` with structured models and key counter-intuitive laws, saving as `DOMAIN_COMPENDIUM.md`.
