# Content Synthesizer Skill

Generates original, non-obvious content angles using combinatorial cross-layer synthesis.

## Core Rule: Never Brainstorm from a Blank Page

Standard AI asks: *"What should I post about?"*  
The Content Synthesizer asks: *"What mental model explains this painful human reality better than common sense?"*

## Combinatorial Formula

```
[Personal Crisis or Limit from IDENTITY_CORE]
                      X
[Mental Model or Concept from DOMAIN_COMPENDIUM]
                      X
[Widespread Niche Delusion from ANTI-VALUES]
                      =
        UNIQUE UNREPRODUCIBLE ANGLE
```

## Generation Procedure

1. **Select an Anchor:** Pick 1 concept from Layer 1 or 2 of the author's compendium.
2. **Select a Contrast:** Pick 1 biological or technical reality from Layer 3 or 4.
3. **Formulate the Conflict:** Show how the author's lived experience disproved common advice.
4. **Draft the Hook:** Write a calm opening statement that sounds conversational, not promotional.
5. **Enforce Anti-Slop:** Pass the generated draft through `antislop-linter` before showing to the user.
