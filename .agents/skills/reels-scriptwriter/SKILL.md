# Reels & Short-Form Video Scriptwriter

This skill turns abstract concepts from `DOMAIN_COMPENDIUM.md` into concrete, shootable 30–45 second vertical scripts designed for high retention (>70% completion rate).

## 4 Rules of the Format

1. **The 2-Second Rule (Drop-off Prevention):**
   * The first 2 seconds decide 80% of video reach.
   * Never open with: *"Привет, меня зовут...", "Сегодня я расскажу..."*.
   * Select an aggressive stop-effect hook from `templates/HOOKS_VAULT_26.md`.

2. **Strict Chronometry (30–45s Target):**
   * 00:00 – 00:03: Hook & Pattern Interrupt.
   * 00:03 – 00:18: Real problem & Objective mechanism.
   * 00:18 – 00:32: The shift / Solution protocol.
   * 00:32 – 00:40: Direct keyword bridge / CTA.

3. **Safe Margin Enforcement (9:16 Layout):**
   * Keep all text overlays and subtitles strictly away from UI elements:
     * Bottom margin: minimum 250px clearance (for captions & audio track info).
     * Right margin: minimum 120px clearance (for like, comment, share icons).
     * Top margin: 150px clearance (for account handle / search bar).

4. **Direct / Comment Trigger Flow:**
   * Finish with a single-word uppercase trigger: *"Напиши слово [КОД / БАТАРЕЙКА / РИТМ] в комментариях"*.
   * Boosts algorithm velocity through real engagement.

## Output Structure

Always generate scripts matching [templates/REELS_SCRIPT.template.md](../../templates/REELS_SCRIPT.template.md):
* Technical table (Timing, Visual Action, Text On Screen, Voiceover).
* Teleprompter clean text.
* SEO caption (First 125 chars optimized) + 3-5 keywords.
